# 🤖 Telegram QR Check Bot

Telegram-бот для сканирования QR-кодов с чеков, получения информации о покупках и удобного разделения счетов между участниками.

## 📋 Описание

Бот позволяет:
- 📸 Сканировать QR-коды с чеков nalog.ru
- 🧾 Получать детальную информацию о покупках через API Proverkacheka
- 👥 Отмечать товары, которые взял каждый участник
- 💰 Автоматически рассчитывать сумму для каждого человека
- 📊 Делить счет справедливо с учетом количества взятых товаров

## 🚀 Быстрый старт

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/SudYar/qr-tg-bot.git
cd qr-tg-bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте переменные окружения:
```bash
cp .env.example .env
# Отредактируйте .env и укажите ваши токены
```

4. Запустите бота:
```bash
python run.py
```

## ⚙️ Конфигурация

### Переменные окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=ваш_токен_telegram_бота
CHEK_TOKEN=ваш_токен_proverkacheka
CHEK_URL=https://proverkacheka.com/api/v1/check/get
```

### Получение токенов

1. **Telegram Bot Token**: Получите у [@BotFather](https://t.me/BotFather)
2. **Proverkacheka Token**: Зарегистрируйтесь на [proverkacheka.com](https://proverkacheka.com)

## 💡 Использование

### Основные команды

- `/start` или `/help` - Приветствие и информация о боте
- Отправьте фото QR-кода - Бот обработает чек и покажет список товаров

### Работа с чеками

1. Отправьте боту фотографию QR-кода с чека
2. Бот распознает код и покажет список товаров с кнопками
3. Нажимайте кнопки "Выбрать" чтобы отметить товары
4. Нажмите "Просуммировать" для расчета итоговых сумм

### Пример работы

```

🤖 Бот отвечает:

Выбрали: , Всего: 0

[Кнопки: 1. Выбрать]

👤 Вася нажимает "Выбрать"
👤 Петя нажимает "Выбрать"

Выбрали: @vasya (1), @petya (1), Всего: 2

[Кнопки: Просуммировать]

💰 Результат:
@vasya должен 45.50 р.
@petya должен 45.50 р.
```

### Модули

#### 🔧 `bot.config`
Управление конфигурацией через переменные окружения

#### 🎯 `bot.handlers`
- `MessageHandlers` - обработка текстовых сообщений и команд
- `CallbackHandlers` - обработка нажатий на inline-кнопки

#### ⚙️ `bot.services`
- `QRScanner` - сканирование QR-кодов с помощью OpenCV
- `ReceiptAPI` - взаимодействие с API Proverkacheka

#### 🛠️ `bot.utils`
- `MessageFormatter` - создание и парсинг сообщений
- `KeyboardFactory` - генерация inline-клавиатур

#### 📦 `bot.models`
- `UserSelection` - управление выбором пользователей

## 🧪 Разработка

### Добавление новых функций

Структура проекта следует принципам:
- **Разделение ответственности** - каждый модуль отвечает за свою задачу
- **Слабая связанность** - модули независимы друг от друга
- **Расширяемость** - легко добавлять новые обработчики и функции

### Пример добавления новой команды

```python
# В bot/handlers/message_handlers.py

def handle_new_command(self, message: Message) -> None:
    """Обработка новой команды"""
    self.bot.send_message(message.chat.id, "Новая функция!")

# В bot/bot.py, метод _register_handlers()

@self.bot.message_handler(commands=['new'])
def handle_new(message):
    self.message_handlers.handle_new_command(message)
```
