#### Технические детали

**Паттерны и принципы:**
- Single Responsibility Principle (SRP)
- Open/Closed Principle (OCP)
- Dependency Inversion Principle (DIP)
- Factory Pattern для создания клавиатур
- Strategy Pattern для работы с API

**Структура кода:**
```
Handlers → Services → Utils/Models
   ↓          ↓          ↓
 Логика   Бизнес-   Вспомогательные
  UI      логика     функции
```

#### Миграция

**Для существующих пользователей:**
1. Установите новые зависимости: `pip install -r requirements.txt`
2. (Опционально) Создайте `.env` файл из `.env.example`
3. Запустите через `python run.py` или продолжайте использовать `python main.py`

**Для новых пользователей:**
1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Скопируйте `.env.example` в `.env` и заполните токены
4. Запустите: `python run.py`
